## 详细设计

### 1. 墙体路径整体移动

#### 枭熊 2 行为参考
- **点击路径线段** → 整体拖动（所有锚点跟随）
- **点击锚点** → 编辑形状（单个锚点移动）
- **双击锚点** → 删除锚点
- **Shift+点击线段** → 添加锚点

#### 实现方案
```
状态机：
  - IDLE（空闲）
  - DRAGGING_PATH（拖动整体）
  - DRAGGING_ANCHOR（拖动锚点）

命中测试优先级：
  1. 锚点（半径 8px）
  2. 线段（距离 < 6px）
  3. 无命中

拖动逻辑：
  - 命中锚点 → DRAGGING_ANCHOR，记录锚点索引
  - 命中线段 → DRAGGING_PATH，记录初始偏移
  - 拖动时：
    - DRAGGING_PATH：所有点 += delta
    - DRAGGING_ANCHOR：单点更新
```

#### 需要修改的文件
- `MapEditorView.Tools.cs`：添加墙体拖动逻辑
- `VmEditWallPathCommand.cs`（新建）：可撤销的墙体编辑命令

### 2. 扇形两步式绘制

#### 枭熊 2 行为参考
1. **第一次拖拽**：
   - 从中心拖拽到终点
   - **预览**：显示圆形（半径 = 拖拽距离）
   - **松手**：半径固定，进入角度调整模式
   
2. **第二次移动**：
   - 鼠标移动（不需要拖拽）
   - **预览**：扇形从圆形裁剪出来，角度跟随鼠标
   - **点击或回车**：确定角度，创建扇形

#### 实现方案
```
状态机：
  - WEDGE_IDLE（空闲）
  - WEDGE_RADIUS（第一步：确定半径）
  - WEDGE_ANGLE（第二步：确定角度）

第一步：
  - MouseDown → WEDGE_RADIUS，记录中心
  - MouseMove → 更新圆形预览
  - MouseUp → 固定半径，进入 WEDGE_ANGLE

第二步：
  - MouseMove → 更新扇形预览（半径固定，角度跟随）
  - MouseDown / Enter → 创建扇形，回到 WEDGE_IDLE
  - Escape → 取消，回到 WEDGE_IDLE
```

#### 需要修改的文件
- `MapEditorView.Tools.cs`：
  - 添加 `_wedgeState` 状态变量
  - 修改 `OnToolDragStart/Update/Complete`
  - 添加 `UpdateWedgeAnglePreview()` 方法

### 3. 控制点系统重构

#### 问题诊断
- 当前可能没有控制点，或者控制点事件未绑定
- 旋转/缩放控制点可能未生成

#### 实现方案
```
控制点类型：
  - TransformHandles（变换控制点）：
    - Corner（4个角）→ 缩放
    - Edge（4条边）→ 拉伸
    - Rotate（顶部）→ 旋转
  
  - PathHandles（路径控制点）：
    - Anchor（锚点）→ 编辑形状
    - Segment（线段中点）→ 整体拖动

生成逻辑：
  - 选中对象 → 根据类型生成对应控制点
  - 控制点显示在 _toolOverlayCanvas
  - 拖动控制点 → 执行对应命令
```

#### 需要修改的文件
- `MapEditorView.Tools.cs`：
  - 添加 `UpdateTransformHandles()` 方法
  - 添加 `OnHandleDragStart/Update/Complete()` 方法
- `VmTransformCommand.cs`（新建）：可撤销的变换命令
